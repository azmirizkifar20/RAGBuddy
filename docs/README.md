# Documentation Map

This folder is organized by document type.

## Primary Entry Points

- [Feature Documentation](./features/README.md)
- [Technical Steering](./steering/README.md)
- [Issue Tracking](./issue/README.md)

## Folder Intent

- `features/`: Feature documentation for `project-rag` itself — currently all *planned* (traced from [`../init.md`](../init.md)), since no code has been implemented yet.
- `steering/`: Technical architecture, routing (CLI/MCP), and stack decisions.
- `issue/`: Bug reports, root cause analysis, and issue findings (empty until implementation begins).

There is no `design-system/` folder: `project-rag` is a backend service (CLI + MCP server) with no UI layer.
